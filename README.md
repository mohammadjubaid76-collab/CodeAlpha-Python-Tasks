## 👨‍💻 Tasks Completed

### ✅ Task 1 — Hangman Game

A simple text-based Hangman game developed using Python.

**Features:**

* Uses 5 predefined words
* Randomly selects a word
* Player guesses one letter at a time
* Maximum 6 incorrect guesses
* Displays guessed letters and word progress
* Console-based input/output

**Concepts Used:**

* `random`
* `while` loop
* `if-else`
* Strings
* Lists
* User input

### ✅ Task 4 — Basic Chatbot

A simple rule-based chatbot that interacts with the user through the console.

**Features:**

* Responds to `hello`
* Responds to `how are you`
* Responds to `bye`
* Handles unknown inputs
* Runs continuously until the user exits

**Concepts Used:**

* Functions
* `if-elif-else`
* `while` loop
* `input()`
* `print()`
