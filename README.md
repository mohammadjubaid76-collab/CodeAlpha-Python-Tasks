## 🚀 Getting Started

Follow these steps to run the Python tasks locally.

### 📋 Prerequisites

Install Python 3 and check that it is available on your system.

    python --version

### 📥 Clone the Repository

    git clone https://github.com/mohammadjubaid76-collab/CodeAlpha-Python-Tasks.git

### 📂 Navigate to the Project Folder

    cd CodeAlpha-Python-Tasks

### ▶️ Run a Python Task

Navigate to the folder containing your chosen task, then run its Python file.

    python filename.py

Replace `filename.py` with the actual Python filename. If the task is inside a subfolder, navigate to that folder first.
